# GGUI Reference

These documents are local reference material for the current GGUI-backed runtime path. They are kept under `docs/reference/ggui` because Jium treats GGUI as infrastructure/reference, not as the product architecture itself.

| Document | Purpose |
|---|---|
| `ggui-overview.md` | How the GGUI render loop works. |
| `ggui-tools.md` | MCP render tools exposed by `services/ggui`. |
| `ggui-json.md` | `services/ggui/ggui.json` configuration. |
| `theming.md` | Theme presets and custom DTCG themes. |
| `writing-mcp-tools.md` | Pattern for authoring domain MCP services. |
| `theme.example.json` | Starter custom theme document. |
